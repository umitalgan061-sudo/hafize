# Storage Kota Uyarısı

Tarayıcı usage/quota değerlerini verirse Privacy Center oran hesaplar.

%80 üzeri kullanım bilgilendirici uyarı üretir.
%90 üzeri kullanım daha yüksek önemde uyarı üretir.

Bu uyarılar otomatik cleanup başlatmaz.

Quota değeri 0 veya geçersizse oran hesaplanmaz.

Estimate API olmadığı halde temel inventory çalışmaya devam eder.

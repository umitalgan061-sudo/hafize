# DOM Contract

Dinamik kullanıcı metinleri createElement + textContent ile oluşturulur.

Surface id'leri dataset üzerinden action handler'a aktarılır.

Panel heading, status, list ve collapse ilişkileri ARIA ile belirtilir.

Global innerHTML/outerHTML kullanımı privacy module'ün güvenlik sözleşmesine aykırıdır.

Yeni dynamic field ekleyen kod aynı boundary modelini izlemelidir.

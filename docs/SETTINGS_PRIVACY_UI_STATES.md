# UI Durumları

Panel normal açık durumda özet, arama, liste ve actions gösterir.

Collapse sonrası body hidden olur ve düğme Göster metnine geçer.

Storage yoksa inventory boş durumunda kalır.

Estimate yoksa browser kartı dash ve bilinmiyor metni kullanır.

Search sonucunda grup başlıkları korunur; eşleşmeyen yüzey satırları gösterilmez.

Destructive action sonrası status alanı işlem sonucunu bildirir.

Destroy sonrası panel ve listener'lar kaldırılır.

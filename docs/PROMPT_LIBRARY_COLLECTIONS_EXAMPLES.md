# Koleksiyon Örnekleri

## Yazı işleri

"Yazı" koleksiyonu altında e-posta, metin düzenleme ve özet istemleri tutulabilir.

## Kod

"Kod" koleksiyonunda inceleme, refactor, test ve hata ayıklama istemleri gruplanabilir.

## Araştırma

"Araştırma" koleksiyonu web araştırması, veri karşılaştırma ve kaynak özeti istemlerini içerebilir.

## Günlük planlama

"Planlama" koleksiyonu günlük görev, toplantı ve karar istemleri için kullanılabilir.

## Yeni kayıt akışı

Varsayılan koleksiyon "Planlama" seçildiğinde yeni oluşturulan prompt otomatik olarak Planlama'ya gider.

Önceden var olan prompt'lar yerlerinde kalır.

## Toplu düzenleme

Kod koleksiyonunda olmayan üç prompt seçilir, hedef "Kod" yapılır ve tek tıkla atanır.

## Arşivleme

Artık kullanılmayan bir koleksiyon silinebilir. Bu işlem prompt metinlerini silmediği için güvenli bir yeniden düzenleme yöntemi sağlar.

## Yedek taşıma

Bir browser profilinden collection export alınır. Başka profilde import edildiğinde aynı isimli koleksiyonlara mapping yapılır.

## Duplicate ID

Başka bir export'tan aynı ID gelirse merge katmanı yeni ID üretir. İsim eşleşmesi yine kullanıcıya tek koleksiyon gösterir.

## Stale data

Silinmiş prompt ID'leri render sırasında temizlenir. Bu nedenle zamanla büyüyen hayalet map kayıtları tutulmaz.

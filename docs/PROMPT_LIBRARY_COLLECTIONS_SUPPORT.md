# Koleksiyon Destek Rehberi

## Koleksiyon görünmüyor

Önce Prompt Library kartının yüklendiğini kontrol edin.

Storage anahtarlarını değiştiren tarayıcı uzantısı olup olmadığını kontrol edin.

## Prompt filtrede görünmüyor

Prompt'un doğru collection selector ile atanıp atanmadığını kontrol edin.

Koleksiyonsuz filtresinde görünmüyorsa map'in stale veya bozuk olabileceği düşünülür.

## Toplu atama olmuyor

Checkbox seçimlerinin yapıldığını kontrol edin.

Hedef koleksiyonun mevcut ve geçerli olduğunu kontrol edin.

## Varsayılan atama şaşırtıyor

Varsayılan collection seçimini kontrol edin.

Mevcut kayıtların retroaktif taşınmaması beklenen davranıştır.

## Import reddediliyor

500 KB sınırını kontrol edin.

JSON'un collection ve assignments object yapısını kontrol edin.

## Collection silindi

Silme prompt'ları silmez. Atamalar kaldırılmış olarak görülmelidir.

## Sayaç yanlış

Sayaç saklanan ayrı değer değildir; prompt listesi ve map üzerinden türetilir.

## Güvenlik sorusu

Collection modülü ağ servisine veri göndermez.

## Destek kaydı

Kullanıcının collection JSON export'u ve prompt export'u ayrı değerlendirilebilir.

## Tanılama

Collection count, assignment count ve default collection değeri local storage'da incelenebilir.

# Change Management

Privacy Center kod değişiklikleri küçük, ölçülebilir PR'lar olarak yapılır.

Storage allowlist değiştiğinde storage key sözlüğü ve test matrix güncellenir.

Destructive behavior değiştiğinde confirmation ve rollback dokümanları birlikte revize edilir.

Report schema değiştiğinde versioning dokümanı güncellenir.

Yeni PWA asset'i eklendiğinde sw-policy ve PWA testleri aynı PR'da değiştirilir.

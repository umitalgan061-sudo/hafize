# Import operations

## Günlük işlem
Önizleme oluştur, kapsamı doğrula ve kullanıcı onayıyla uygula.

## Kontrol
Apply öncesi güncel storage tekrar okunur.

## İzleme
Import sonucu status text ile bildirilir.

## Cleanup
Geçersiz girişler plan dışında tutulur.

## Recovery
Recovery snapshot gerektiğinde indirilebilir.

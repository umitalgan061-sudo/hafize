# Arama ve Sıralama

Privacy Center yüzey listesi search, name sort, size sort ve only-present filtrelerini birlikte destekler.

Search yalnız label ve description üzerinde çalışır.

Size sort büyük alanları üstte gösterir.

Only-present boş yüzeyleri gizler.

Bu UI filtreleri storage state olarak persist edilmez.

Clear eyleminin allowlist kapsamı filtrelerden bağımsızdır.

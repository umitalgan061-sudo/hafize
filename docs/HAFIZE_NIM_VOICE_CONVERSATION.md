# Configured Turkish NIM voice conversation

Optional NIM Turkish TTS and ASR in the existing voice screen, discovered only from authenticated configured capability status. TTS uses the same unlocked audio element as downloaded voices and is cancellable. ASR requests browser echo cancellation, noise suppression and automatic gain control on a single capture stream, retains a short preroll, detects speech and sends only the utterance as 16 kHz PCM WAV; abort/close releases tracks and cancels request. This is a batch speech recognition adapter, not an official real-time NVIDIA streaming ASR service or guaranteed full-duplex iPhone support. Browser recognition remains default. Selecting NIM ASR explicitly sends voice to the configured backend; TTS selection sends text. No new endpoint, GPU, paid service, or provider credentials were provisioned. Physical device tests require configured services and the user's microphone. PWA v192.

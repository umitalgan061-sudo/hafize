# Dil ve Metin

Privacy Center kullanıcıya görünen bütün metinleri Türkçe tutar.

Storage key adları kod sabiti olarak kalır; kullanıcı arayüzünde teknik key'ler gösterilmez.

Yüzey adları kısa, açıklamalar işlev odaklıdır.

Confirmation metinleri veri değerlerini içermez.

Gelecekte çok dil desteği eklenirse storage contract değişmemeli, yalnız COPY katmanı çevrilmelidir.

Testler davranışsal token'ları mümkün olduğunca stabil bırakmalı; dil değişiminde kaynak regex bağımlılığı azaltılmalıdır.

# Verified release tools

Adds owner-session gated `github_release` with explicit per-action production approval. Open a ready PR, validate exact SHA, same repo, safe branch, main base, complete file list, fixed CI workflow and clean mergeability, recheck after approval, squash merge. Allowlisted paths initially Hafize UI and Borsa frontend/worker; other files, workflows, credentials and policy are blocked. Dispatch fixed Hafize Firebase or Borsa Cloudflare workflow at current main with separate approval. Dispatch is not success; exact CI and live marker must be verified. `github_inspect jobs` returns job/step status. Existing browser rendering and orchestrator resume may be used when configured. Render API/hook, full browser interaction, draft conversion, arbitrary repo release and durable long-running restart recovery are not implemented here. No deployment credential is exposed or configured by this PR.

# Composer Ekleri — Gelecek İşler

Bu tur kapsamı dışında bırakılan fikirler:

- gerçek tokenizer tabanlı context estimate
- git diff biçiminde iki dosya karşılaştırma
- kalıcı attachment history için ayrı opt-in storage
- gelişmiş secret detector rule paketleri
- tarayıcı File System Access API entegrasyonu
- sunucuya kontrollü document upload

Bu fikirler mevcut in-memory privacy modelini sessizce değiştirmemelidir. Kalıcı veya remote attachment fikri yeni bir security/data-retention tasarımı gerektirir.

# Diagnostics operations

## Tarama
Panel mount olduğunda ilk raporu üretir.

## Repair
Güvenli repair öncesinde checkpoint oluşturur.

## Quarantine
Invalid records capped local quarantine içine alınır.

## Undo
Tek son repair checkpoint'i geri alınabilir.

## Export
Recovery snapshot kullanıcı tarafından indirilir.

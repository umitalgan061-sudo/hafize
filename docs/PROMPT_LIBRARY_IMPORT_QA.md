# Import QA planı

## Fonksiyonel
Geçerli yedek, boş dosya, bozuk JSON, duplicate id, kapasite doluluğu ve cancel akışları kontrol edilir.

## Güvenlik
DOM injection, network API, oversized input ve onaysız write kontrol edilir.

## Accessibility
Dialog semantics, focus restoration, Escape, Tab loop ve mobil yerleşim kontrol edilir.

## PWA
Yeni JS/CSS asset'leri index ve shell cache sözleşmesinde bulunur.

## Regression
Mevcut Prompt Library export/import fonksiyonları ve smart-fill ile aynı storage anahtarının davranışı korunur.

## Release
Source contract testleri ve tam check komutu birlikte değerlendirilir.

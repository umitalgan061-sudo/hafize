# Destek Rehberi

Kullanıcı "Hafize ne saklıyor?" diye sorarsa yüzey bazlı açıklama verilir; ham localStorage değeri istenmez.

Kullanıcı "neden bilinmeyen alan var?" derse bunun privacy center'ın tanımadığı veya başka özelliğe ait storage alanı olabileceği açıklanır.

Kullanıcı yanlışlıkla veri sildiyse privacy center'ın kendi işlemi geri alınabilir değildir. Bu nedenle workspace backup önerisi ürün akışının ayrı bir güvenlik katmanıdır.

Kullanıcı rapor isterse content-free JSON raporu kullanılabilir.

Storage estimate görünmüyorsa tarayıcı API'sinin desteklenmemesi normaldir.

Destek ekibi token, credential veya session değerlerinin ekran görüntüsünü istememelidir.

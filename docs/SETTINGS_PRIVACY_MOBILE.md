# Mobil UX

Mobil ekranlarda veri yüzeyi satırları dikey yerleşime geçer.

Arama alanı tam genişlikte kalır. Temizleme düğmesi parmak hedefi olarak satır genişliğine yaklaşır.

Özet kartları üç kolon yerine tek kolon olur.

Gizlilik raporu ve özet kopyalama actions aynı toolbar içinde kalır.

Collapse davranışı mobilde de aria-expanded ile aynı durumu taşır.

Klavye kısayolunun mobilde kullanılmaması sorun değildir; butonlar erişilebilir ana yol olarak kalır.

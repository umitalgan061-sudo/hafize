# Eski smart-insert dalı notu

Bu dosya geçici bir merge notudur. Güncel main dalında prompt değişken doldurma özellikleri `prompt-library-smart-fill.js`, komut paleti ve ilgili yardımcı modüller üzerinden yürütülmektedir.

Stale bir dalın doğrudan main üzerine alınması paralel özellik sistemleri oluşturabilir. Güvenli geliştirme kuralı gereği bu turda güncel main tabanından yeni bir branch açılması tercih edilir.

# Recovery JSON import

Diagnostics tarafından oluşturulan recovery JSON, Prompt Library import preview tarafından tanınır.

Recovery zarfındaki prompts alanı mevcut Prompt Library items biçimine dönüştürülür.

Import preview yine normal validation, collision ve capacity kurallarını uygular.

Recovery dosyası uygulanmadan önce kullanıcıya kaynak türü gösterilir.

# Composer History — Kabul Kriterleri

## AC-01

Gönderilen boş olmayan mesaj history'ye eklenir.

## AC-02

Aynı mesaj ikinci kez gönderildiğinde duplicate kayıt oluşmaz.

## AC-03

History 40 kayıt üstüne çıkmaz.

## AC-04

Tek kayıt 12.000 karakter üstüne çıkmaz.

## AC-05

Arrow navigation yalnız composer edge position'da devreye girer.

## AC-06

IME composition sırasında history shortcut'ı çalışmaz.

## AC-07

History navigation mevcut taslağı korur ve listenin sonundan sonra geri yükler.

## AC-08

Panel araması yalnız yerel değerler üzerinde yapılır.

## AC-09

Paneldeki `Kullan` düğmesi otomatik submit oluşturmaz.

## AC-10

Tek kayıt silme mevcut diğer kayıtları değiştirmez.

## AC-11

Toplu temizleme confirmation gerektirir.

## AC-12

Backup import 512 KB üzerinde reddedilir.

## AC-13

Malformed import mevcut history'yi değiştirmez.

## AC-14

Retention 0 seçildiğinde yeni kayıt saklanmaz.

## AC-15

Retention 10/20/40 değerlerine sınırlandırılır.

## AC-16

History UI plain text render eder.

## AC-17

History özelliği network request üretmez.

## AC-18

Tüm static history assetleri PWA shell'e dahildir.

## AC-19

Escape paneli kapatır ve toggle odağına döner.

## AC-20

Module destroy sonrası listener leak bırakmaz.

## AC-21

Feature yokken composer ana gönderim akışı çalışmaya devam eder.

## AC-22

Güncellenmiş service worker cache version mevcut asset listesini temsil eder.

# Detached public research tasks

Owner-authenticated POST /api/orchestrator/runs accepts an explicit public research goal. The planner and every subsequent tool invocation are restricted to existing low-risk public web reads and internal reasoning, not repositories, private memory, files, credentials, agent delegation or external mutations. The returned run ID means a validated plan was checkpointed, not success. Execution has its own cancellation scope, independent of the initiating HTTP response. User can view task details and cancel from advanced settings; process shutdown aborts detached work. Local SQLite checkpoints and encrypted backup recovery remain, but no free Render persistent disk, external database, always-on worker or process-restart guarantee is introduced. PWA v194. No recurring schedule created.

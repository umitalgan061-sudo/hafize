# Gözlemlenebilirlik

Privacy Center kalıcı telemetry yazmaz.

Operasyonel olarak gözlemlenebilir bilgiler:
- panel status mesajları,
- local event detail içindeki action/id/removed,
- kullanıcı tarafından indirilen privacy report.

Sunucu loglarında yeni privacy payload oluşturulmaz.

Support, kullanıcının privacy report dosyasını paylaşması halinde bile bunun yalnız metadata formatı olduğunu doğrulayabilir; raw content olmaması feature contract'ının parçasıdır.

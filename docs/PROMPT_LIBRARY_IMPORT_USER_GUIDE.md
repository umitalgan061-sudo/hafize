# Import kullanıcı rehberi

## İçe aktar
Kütüphane kartındaki İçe aktar düğmesine basın ve JSON yedeğini seçin.

## Önizleme
Dosya adı, boyut, mevcut kayıt, aktarılacak kayıt, çakışma ve kapasite özetini inceleyin.

## Onay
İçe aktar düğmesi yalnızca uygun kayıt varsa etkin olur.

## İptal
İptal veya Escape hiçbir prompt kaydını değiştirmez.

## Duplicate
Çakışan ID yeni bir kimliğe taşınır; eski kayıt korunur.

## Limit
1 MB dosya ve 120 prompt kapasitesi uygulanır.

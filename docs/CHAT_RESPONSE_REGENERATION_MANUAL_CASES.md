# Manuel Kabul Cases

## MC-01 Normal
Bir assistant response sonrası Yeniden üret ile yeni içerik üret.

## MC-02 Failure
Network kapat ve regeneration başlat. Eski content korunmalı.

## MC-03 Restore
Yeni content sonrası Önceki yanıtı getir kullan. Önceki content current olmalı.

## MC-04 Picker
Varyantlar panelinde ikinci önceki response'u seç. Seçilen response current olmalı.

## MC-05 Instruction
Yönergeyle yeniden üret seç ve Daha kısa preset'i kullan.

## MC-06 Custom
Özel yönerge gir ve yeni response bekle.

## MC-07 Feedback
Positive ve negative toggle davranışını kontrol et.

## MC-08 Copy
Kopyala ile current response clipboard'a aktar.

## MC-09 Tools
Tools açıkken regeneration agent endpoint kullanmalı.

## MC-10 Offline
Offline iken request gönderilmemeli.

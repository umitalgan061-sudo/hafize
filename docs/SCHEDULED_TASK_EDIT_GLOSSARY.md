# Schedule Edit Glossary

**scheduled:** Gelecekte çalıştırılmak üzere bekleyen görev.

**running:** Worker tarafından claim edilmiş görev.

**update:** Mevcut scheduleId korunarak düzenlenen mutation.

**quick postpone:** Yalnız `runAt` alanını ileri alan hızlı işlem.

**repeat-plan:** Eski kaydı değiştirmeden yeni schedule oluşturan işlem.

**bulk action:** Seçili planlandı kayıtlarına ardışık tekil mutation uygulayan UI işlemi.

**owner:** Schedule kaydının principal subject ile eşleşen sahibi.

**public schedule:** ownerId gibi iç yetkilendirme alanlarını dışarı vermeyen response modeli.

# Prompt Smart Fill Scope

Bu turda yerel Prompt Library için değişkenli istemleri uygulama içi bir dialog üzerinden doldurma deneyimi geliştirilmiştir.

Kapsam: değişken alanları, canlı önizleme, sınırlı yerel presetler, güvenli composer aktarımı, no-submit davranışı, erişilebilirlik, PWA cache ve regresyon kontratları.

Diff bütçesi base `998547ddc63e8b3a62ad74c3ed49614df62620d4` ile karşılaştırmada 3000 değişen satır altında tutulmuştur.

# Görev Ayrıntıları

Görev satırındaki Ayrıntı düğmesi tam görev metni ve mevcut görünür metadata'yı modal içinde gösterir.

Görüntülenen alanlar görev, durum, ajan, çalışma zamanı, deneme sayısı, Trace ID ve varsa son hata metnidir.

Bu ekran salt-okunurdur. Yeni HTTP isteği oluşturmaz, görev durumunu değiştirmez ve form submit etmez.

Dialog açıldığında önceki odak korunur. Kapatıldığında odak geri döner; Escape kullanılabilir.

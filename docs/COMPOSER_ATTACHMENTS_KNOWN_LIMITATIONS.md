# Composer Ekleri — Bilinen Sınırlar

1. Secret scanner yalnız bilinen regex desenlerini bulur.
2. Clipboard file desteği browser capability'lerine bağlıdır.
3. Drag/drop mobilde her zaman kullanılabilir olmayabilir.
4. Attachment queue refresh sonrası geri gelmez.
5. Gerçek model token hesabı yapılmaz; karakter bütçesi kullanılır.
6. Binary detection heuristic'tir.
7. Undo son insert state'iyle sınırlıdır.
8. Attachment metni kullanıcı normal chat gönderirse conversation history'ye girebilir.

Bu sınırlar feature sözleşmesinin parçasıdır; security guarantee olarak yorumlanmamalıdır.

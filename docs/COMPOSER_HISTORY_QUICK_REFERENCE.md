# Composer History — Hızlı Referans

## Kısayollar

- `↑`: önceki gönderi
- `↓`: sonraki gönderi
- `Ctrl/⌘ + Shift + H`: history paneli
- `Escape`: paneli kapat

## Storage

History: `hafize.composer-history.v1`

Settings: `hafize.composer-history.settings.v1`

Varsayılan limit: 40

Alternatif limitler: 10 / 20 / 40

Kapalı: 0

## Backup

Export: JSON

Import: JSON

Import sınırı: 512 KB

## Safety

12.000 karakter kayıt limiti.

Boş kayıt yok.

Duplicate kayıt yok.

HTML execution yok.

Remote history sync yok.

## Troubleshooting

Storage boşsa history de boş görünür.

IME açıkken arrow shortcut beklenir şekilde pasiftir.

Cursor ortadaysa arrow tuşları normal textarea davranışını korur.

Disabled history yeni kayıt oluşturmaz.

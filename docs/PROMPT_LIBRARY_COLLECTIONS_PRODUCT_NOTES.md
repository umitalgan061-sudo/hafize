# Koleksiyon Ürün Notları

Koleksiyonlar Prompt Library'nin klasör katmanıdır.

Amaç tekrar kullanılan istemleri çalışma alanlarına ayırmayı kolaylaştırmaktır.

Etiketlerden farklı olarak koleksiyon tekil bir ana aidiyet temsil eder.

Örnek:
- Yazı
- Kod
- Araştırma
- Planlama

"Yönet" paneli metadata işlemlerini ayrı tutar.

Prompt satırı assignment selector'ı doğrudan kullanım noktasında gösterilir.

Bulk assignment seçimli çalışma akışlarını hızlandırır.

Default collection yeni kayıtların otomatik düzenlenmesine yardımcı olur.

Collection filter ana listeyi değiştirmeden görünürlüğü sınırlar.

Yedek yalnız collection metadata ve assignment ilişkisini taşır. Prompt gövdeleri mevcut Prompt Library export'u ile korunmalıdır.

Bu ayrım data duplication ve farklı storage şemalarının drift riskini azaltır.

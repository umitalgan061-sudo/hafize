# Bağlantılar kullanıcı rehberi

## Bağlantılar nasıl açılır?

Sol menüden “Bağlantılar” çalışma alanını seç.

## Genel kart

Genel kart GitHub, Google/Gmail ve Canva connector kapasitesinin hazır olup olmadığını özetler.

## Gmail

Gmail kartı bağlantının kullanıcı hesabı için mevcut olup olmadığını gösterir.

“Bağlı” görülmesi, panelin mail içeriğini burada açtığı anlamına gelmez.

## Canva

Canva kartı kullanıcı bağlantısını gösterir.

## GitHub

GitHub kartı salt-okunur workspace hazırlığını gösterir.

Bu panelden commit veya PR merge çalıştırılmaz.

## Yenile

“Durumları yenile” mevcut server status uçlarını tekrar sorgular.

## Gizle

Genel karttaki “Gizle” kontrolü bağlantı kartlarını geçici olarak saklar.

Tercih bu oturum süresince korunabilir.

## Güvenlik

Connector tokenları bu panelde gösterilmez.

## Sorun yaşarsan

Önce oturumun açık olduğunu kontrol et. Sonra refresh kullan. “Devre dışı” görülüyorsa server connector yapılandırması eksik olabilir.

## Gizlilik

Bu panel mail, Canva dosyası veya GitHub dosya içeriğini depolamaz.

## Gösterilen veri

Yalnız gerekli durum kodları ve açıklayıcı kısa metinler gösterilir.

# Composer Ekleri — Kullanıcı Senaryoları

## Kod inceleme
Bir TypeScript dosyası seç, gerekli satır aralığını daralt, Kod incele hızlı aksiyonunu seç ve üretilen composer metnini incele.

## Bug arama
Birden fazla kaynak dosyası seç, ilgili range'leri belirle ve Hata ara ile analiz talebi oluştur.

## Özet
Markdown veya JSON metnini seçip Özetle aksiyonuyla açıklama talebi hazırla.

## Gereksinim
Örnek kod veya config seçip Gereksinime dönüştür ile uygulanabilir gereksinim listesi iste.

## Hassas dosya
Credential içeren dosya seçildiğinde risk uyarısını gör. Kullanıcı onaylamazsa metin composer'a yazılmaz.

## Partial context
Büyük dosyadan yalnız gerekli 100–200 satırı seçerek model context'ine daha küçük payload hazırla.

## Clipboard-only
Dosyayı composer'a eklemeden seçili range'i Kopyala ile başka bir uygulamaya aktar.

## Recovery
Insert sonrası metni yanlış yerde görürsen Son eklemeyi geri al ile önceki composer durumuna dön.

# Composer Ekleri — Changelog

## İlk sürüm
Local text/code file picker ve staging queue.

## Range sürümü
400 satır bounded range selection eklendi.

## Insertion sürümü
Cursor/selection aware insert, atomic capacity check ve undo eklendi.

## Copy sürümü
Seçili range için clipboard copy eklendi.

## Security sürümü
Pre-read byte validation ve local secret risk scanner eklendi.

## UX sürümü
Özetle, Kod incele, Hata ara ve Gereksinime dönüştür hızlı analiz aksiyonları eklendi.

## PWA sürümü
Shell cache v37 ile attachment static assetleri cache listesine alındı.

## Privacy ilkesi
Attachment content persistent storage'a alınmadı.

# Operasyonel Güvenlik

Privacy Center yalnız local storage yüzeylerinde çalışır.

Toplu temizleme bilinmeyen key'leri korur.

Credential benzeri alanlar allowlist'e dahil değildir.

Rapor indirme ve copy işlemleri kullanıcı eylemi olmadan başlamaz.

Kota uyarısı otomatik deletion başlatmaz.

Workspace Backup ile privacy report birbirine karıştırılmaz.

Rollback kod ile data lifecycle'ı birbirinden ayırır.

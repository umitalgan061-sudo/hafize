# Diagnostics kullanıcı rehberi

## Tara
Kütüphane sağlığını açın ve Tara düğmesine basın.

## Okuma
Yeşil değerler sorun görülmediğini, uyarı değerleri inceleme gerektiğini gösterir.

## Güvenli onarım
Normalize ve orphan ilişkilerini sınırlandırmak için kullanılır.

## Geçersiz kayıt
Geçersiz kayıtları kaldır eylemi önce karantinaya taşır.

## Geri alma
Karantinayı geri al geçersiz kayıtları yeniden import eder.

## Undo
Son onarımı geri al son repair checkpoint'ini kullanır.

## Yedek
Yedek indir repair öncesi recovery dosyası oluşturur.

# Smart Fill Kullanıcı Rehberi

## Değişkenli istemi kullanma

Prompt Library içinden bir istemin `Kullan` düğmesine bas. İstem `{{konu}}` gibi değişkenler içeriyorsa doldurma paneli açılır.

Her alanı doldur. Sağdaki/alt bölümde oluşan önizlemeyi kontrol et. Sonra `Mesaja aktar` düğmesine bas. Metin composer'a gelir; gönderim yapılmaz.

## Değişken seti kaydetme

Aynı değerleri sık kullanıyorsan `Seti kaydet` ile yerel bir set oluştur. Set adı yalnız cihazında saklanır.

Daha sonra set listesinden seçtiğinde alanlar otomatik dolar. `Setleri temizle` yalnız bu istemin setlerini kaldırır.

## Önizleme kopyalama

`Önizlemeyi kopyala` yalnız oluşturulan son metni clipboard'a taşır. Prompt kaydı, geçmiş sohbet veya başka bilgiler kopyalanmaz.

## Command palette

Composer'a `/prompt` yazarak istem seçiciyi aç. Arama metnini devam ettirdikçe başlık, etiket ve gövde eşleşmeleri bulunur.

`Ctrl+Shift+O` veya macOS'ta `⌘+Shift+O` aynı seçiciyi açıp kapatır.

Ok tuşlarıyla hareket et, Enter ile seç, Escape ile kapat.

Değişkenli bir istem seçersen Smart Fill paneline geçersin.

## Gizlilik

Smart Fill ve palette cihaz üzerinde çalışır. Değişken değerleri analytics için gönderilmez.

## İyi kullanım

Uzun müşteri listelerini değişken alanına yapıştırmak yerine gerektiğinde kısa ve kontrollü değerler kullan. 1000 karakterlik sınır vardır.

İstem içinde gereksiz değişken kullanmamak önizleme akışını daha okunur tutar.

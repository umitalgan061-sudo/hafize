# Health Center Hızlı Başvuru

## Sağlık

`Kütüphane sağlıklı` hata bulunmadığını gösterir.

## Hata

Hata sayısı sıfır değilse önce `Hatalar` filtresini aç.

## Uyarı

Uyarılar çoğunlukla bakım veya referans ilişkileridir.

## Bilgi

Bilgi bulguları öneridir; veri bozukluğu değildir.

## Onarım

Önce export, sonra kullanıcı onayı, ardından `Güvenli onarım`.

## Export

`Raporu kopyala` hızlıdır.

`Raporu indir` bounded JSON dosyası üretir.

`Sorunlu promptları indir` yalnızca hata/uyarı ile ilişkili prompt kayıtlarını içerir.

## Limitler

120 prompt, 40 collection, 600 revision, 240 issue.

## Gizlilik

Network çağrısı yoktur.

## Rollback

Health asset'lerini revert etmek yeterlidir.

# Smoke Test

## Açılış
Sohbet yüklenir ve mevcut conversation görünür.

## Yanıt
Bir assistant response oluşturulur.

## Actions
Yeniden üret, Kopyala ve feedback buttons görünür.

## Regeneration
Son response için yeniden üret tıklanır ve stream başlar.

## Restore
Yeni response geldikten sonra Önceki yanıtı getir görünür.

## Cycle
Restore tekrarlandığında response history bounded biçimde döner.

## Error
Ağ kesildiğinde eski response korunur.

## Mobile
Action row küçük ekranda wrap olur.

## Keyboard
Tab ve Enter ile action kullanılır.

## PWA
Page reload sonrası conversation storage korunur.

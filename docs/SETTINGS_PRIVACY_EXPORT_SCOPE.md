# Export Scope

Privacy report yalnız envanter metadata'sıdır.

Export scope aşağıdaki alanları içerebilir:
- surface id
- presence
- key count
- byte count
- total counts
- browser usage/quota estimate

Export scope raw storage values içermez.

Summary scope daha kısa insan-okur metindir.

Export kullanıcı tarafından açıkça başlatılır ve cihaz üzerinde oluşturulur.

# Diagnostics release checklist

## Ürün
Tarama ve repair görünür, anlaşılır ve kullanıcı onaylıdır.

## Veri
Repair duplicate kayıtları korur; orphan referansları sınırlandırır.

## Gizlilik
No-network local-only tasarım korunur.

## QA
Diagnostics contract, data, repair, lifecycle ve recovery paketleri birlikte çalıştırılır.

## Operasyon
Recovery backup dosyası onarım öncesi kanıt olarak kullanılabilir.

## Rollback
UI modülü kaldırılabilir; ana kayıt formatı korunur.

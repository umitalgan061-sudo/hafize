## Ana iyileştirme

Yerel Prompt Library için akıllı değişken doldurma deneyimi.

## Kapsam

Değişkenli istemlerde uygulama içi dialog, ayrı alanlar, canlı önizleme, yerel preset setleri, kopyalama, güvenli composer aktarımı, keyboard focus yönetimi ve PWA asset entegrasyonu.

## Kalite

Kaynak kontratları, storage izolasyonu, DOM güvenliği, no-submit davranışı, accessibility, PWA, limitler ve kullanıcı yolculuğu testleri eşlik eder.

## Güvenlik

Sunucu ağına yeni istek eklenmez. Secret, token veya authorization header işlenmez. Dinamik metin güvenli DOM API'leriyle basılır.

## Test notu

Tam yerel `npm run check` bu oturumda çalıştırılamadı; GitHub Actions sonucu da commit için mevcut değildi. Bu sınırlama PR'da açıkça belirtilmelidir.

## Rollback

PR revert edilerek smart-fill ve ona bağlı asset/test/dokümantasyon değişiklikleri geri alınabilir.

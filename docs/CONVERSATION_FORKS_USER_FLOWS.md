# Konuşma Dalları Kullanıcı Akışları

## Mesajdan branch
Mesaj → Buradan dallandır → Onay → Yeni dal → Yeni soru.

## Parent'a geri dönme
Sidebar'dan parent conversation normal sohbet listesi üzerinden açılır.

## Child branch'e geçme
Konuşma dalları panelinden Aç seçilir.

## Klavye
Ctrl / Cmd + Shift + F → son mesajdan dallandırma dialogu.

## Ağ davranışı
Fork onayı sonrasında otomatik model çağrısı yoktur. Kullanıcı yeni mesaj gönderene kadar sadece local state değişmiştir.

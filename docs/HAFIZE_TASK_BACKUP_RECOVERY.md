# Task checkpoint backup recovery

The existing encrypted backup already collected up to 200 orchestrator run records but restore omitted them. Restore now imports validated missing records without overwriting existing tasks. All restored tasks containing a mutation are history-only, even if the snapshot was taken before mutation dispatch; old approvals are discarded. Explicit resume of restored read-only plans is limited to currently available low-risk replay-safe tools, including later critic revisions. This does not automatically start work or provide durable storage on a free Render instance. External backup targets remain operator-configured. The actual Render workspace was observed to have a free web service, no attached disk, no Key Value or Postgres service. No additional paid resource was created.

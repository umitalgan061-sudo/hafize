# Import regression contract

Import davranışı aşağıdaki alanlarla korunmalıdır:

- 1 MB file guard
- array ve wrapper payload compatibility
- duplicate ID re-key
- capacity skip
- no-write-before-confirm
- no network
- StorageEvent refresh
- modal close on Escape

Bir değişiklik bu sözleşmelerden birini bozarsa import paketi yeniden gözden geçirilmelidir.

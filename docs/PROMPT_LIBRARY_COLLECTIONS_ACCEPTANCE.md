# Koleksiyon Acceptance Kriterleri

AC01: Kullanıcı 24'e kadar koleksiyon oluşturabilir.

AC02: Koleksiyon adı boşsa kayıt yapılmaz.

AC03: Aynı isim ikinci kez oluşturulamaz.

AC04: Koleksiyon yeniden adlandırılabilir.

AC05: Koleksiyon silindiğinde bağlı prompt korunur.

AC06: Prompt tekli selector ile koleksiyona atanabilir.

AC07: Prompt selector "Koleksiyonsuz" seçildiğinde map girdisi silinir.

AC08: Seçilen prompt'lar bulk assignment ile aynı koleksiyona atanabilir.

AC09: Collection filter sadece ilgili satırları gösterir.

AC10: Koleksiyonsuz filter atamasız satırları gösterir.

AC11: Default collection yeni prompt'lara uygulanır.

AC12: Default collection mevcut prompt'ları taşımaz.

AC13: Collection export JSON üretir.

AC14: Collection import duplicate name ile tek kayıt tutar.

AC15: Stale assignment render öncesi temizlenir.

AC16: Dinamik collection text güvenli DOM API'leri ile yazılır.

AC17: 500 KB üzeri import reddedilir.

AC18: Ctrl/Meta+Shift+O collection filter'a odaklanır.

AC19: PWA shell collection assetlerini içerir.

AC20: Rollback temel prompt storage davranışını bozmaz.

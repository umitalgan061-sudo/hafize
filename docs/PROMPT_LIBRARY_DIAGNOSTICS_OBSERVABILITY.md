# Diagnostics observability

Diagnostics kalıcı bir metrics sistemi değildir.

Kullanıcıya gösterilen metrikler:
- rawCount
- normalizedCount
- invalidCount
- duplicateIdCount
- invalidUseCount
- orphan collection members
- orphan revision refs
- snapshot mismatches

Rapor kopyalama yalnızca özet veriyi clipboard'a yazar.

Network logging veya remote analytics kullanılmaz.

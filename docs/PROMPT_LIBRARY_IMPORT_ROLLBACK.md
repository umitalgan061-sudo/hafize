# Import rollback

Import preview katmanı revert edildiğinde Prompt Library ana storage key'i değişmez.

Diagnostics veya safety katmanı revert edildiğinde mevcut prompt kayıtları silinmez.

Yanlış import sonucu için recovery JSON kullanılır.

Repair checkpoint mevcut oturumdaki son repair'i geri almak için kullanılır.

Quarantine, kalıcı silmeden önce yerel güvenlik ağıdır.

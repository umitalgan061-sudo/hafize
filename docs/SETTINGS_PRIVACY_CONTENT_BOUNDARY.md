# İçerik Sınırı

Inventory kodu raw storage value'yi summary içine taşımaz.

Report yalnız id, present, keys, bytes ve totals metadata'sı kullanır.

Human-readable summary surface label ve byte özetleriyle sınırlıdır.

UI açıklamalarında teknik storage key yazılmaz.

Unknown key değeri hiç okunabilir metin olarak rapora girmez.

Bu boundary privacy feature'ın ana kabul kriterlerinden biridir.

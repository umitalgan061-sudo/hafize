# Koleksiyon Kullanıcı Rehberi

## Koleksiyon oluşturma

İstem Kütüphanesi içindeki Koleksiyonlar bölümünde "＋ Koleksiyon" seçilir.

Ad boş bırakılamaz ve 36 karakteri aşan bölüm kırpılır.

Aynı isimde ikinci bir koleksiyon oluşturulamaz.

## Prompt atama

Her prompt satırındaki Koleksiyon seçicisinden hedef belirlenir.

"Koleksiyonsuz" seçildiğinde mevcut atama kaldırılır.

## Toplu atama

Prompt listesinde checkbox ile birden fazla kayıt seçilir.

"Seçilen istemlerin hedef koleksiyonu" alanından hedef belirlenir.

"Seçilenleri ata" ile tek işlemde tüm seçimler taşınır.

## Filtre

"Tüm koleksiyonlar" tüm prompt'ları gösterir.

"Koleksiyonsuz" yalnızca ataması olmayanları gösterir.

Belirli koleksiyon seçildiğinde yalnız o koleksiyonun prompt'ları görünür.

## Varsayılan koleksiyon

Yeni istemler için bir varsayılan koleksiyon seçilebilir.

Bu seçim mevcut kayıtları değiştirmez.

Seçim kapatıldığında yeni prompt'lar otomatik sınıflandırılmaz.

## Koleksiyon silme

Silme işleminden önce onay istenir.

Silinen koleksiyonun prompt'ları korunur ve koleksiyonsuz hale gelir.

## Yeniden adlandırma

Yönet panelinden koleksiyon adı güncellenebilir. Atamalar değişmeden kalır.

## Yedek

Koleksiyon yedeği collection tanımları ve assignment map içerir.

Prompt metinlerinin ayrı Prompt Library export'u ile yedeklenmesi gerekir.

## İçe aktarma

Geçerli collection yedeği mevcut koleksiyonlarla isim bazında birleştirilir.

Mevcut prompt içerikleri import tarafından değiştirilmez.

## Klavye

Ctrl/Meta+Shift+O koleksiyon filtresine odaklanır. Input, textarea ve select içinde bu davranış devralınmaz.

# Clear Scope

Single-surface clear yalnız hedef surface exact/prefix alanlarını kaldırır.

Data-group clear yalnız data olarak sınıflandırılmış surface'ları hedefler.

Preference clear yalnız preference surface'ları hedefler.

Full known clear tüm allowlist surface'larını hedefler.

Unknown keys her scope'ta korunur.

Clear scope search veya sort state tarafından değiştirilmez.

# Güvenlik Özellikleri

P1: Unknown-key preservation.

P2: Allowlist-only deletion.

P3: Content-free reporting.

P4: Explicit destructive confirmation.

P5: No network transport.

P6: Bounded key scan.

P7: Bounded report size.

P8: Text-only DOM insertion.

P9: PWA API cache separation.

Bu özelliklerden biri değişirse security regression testi eklenmelidir.

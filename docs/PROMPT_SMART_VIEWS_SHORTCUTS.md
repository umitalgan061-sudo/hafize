# Akıllı Görünümler Kısayolları

## Ctrl / ⌘ + Shift + Q

Hızlı sorgu oluşturucunun metin alanını odaklar.
Kısayol input, textarea, select veya contenteditable alanının içindeyken devre dışıdır.

## Enter

Builder alanlarında normal form kontrol davranışı korunur.
Kısayol submit tetiklemek için kullanılmaz.

## Tab

Panel kontrolleri doğal tab sırasıyla erişilebilir.
Kapat/göster düğmesi odağı kaybetmez.

## Erişilebilirlik ilkesi

Klavye kısayolu tek başına bir özelliğin tek erişim yöntemi değildir.
Aynı işlev görünür düğme üzerinden de çalışmalıdır.
Kısayol başka bir uygulama kontrolünü sessizce ele geçirmemelidir.

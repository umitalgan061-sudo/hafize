# Diagnostics erişilebilirlik sözleşmesi

## Semantik
Panel section olarak oluşturulur ve aria-labelledby kullanır. Rapor listeleri role=list ve metrikler okunabilir metin içerir.

## Butonlar
Tara, Yedek indir, Güvenli onarımı uygula ve Geçersiz kayıtları kaldır gerçek button elementleridir.

## Durum
Tarama sonucu status alanında kullanıcıya bildirilir.

## Renk
Durum yalnızca renge bağlı değildir; is-warning ve is-ok sınıfları metriklerle birlikte görünür içerik taşır.

## Klavye
Tab sırası doğal DOM sırasını izler. Modal import akışının focus trap'i diagnostics panelinden bağımsızdır.

## Mobil
Metrik grid tek sütuna düşer.

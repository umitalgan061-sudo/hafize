# Persistent active microphone session

Optional configured NIM batch ASR uses a single microphone acquisition throughout an active voice conversation. Recognition turns detach and reattach a consumer instead of reopening the physical stream; idle silence no longer causes a one-minute microphone recycle. While transcribing, samples are discarded, not uploaded or queued. New user turns are rearmed as soon as the request is submitted, including while Hafize speaks. Explicit mute, pause, close, pagehide/background and engine switch release the microphone. Browser-only recognition remains unchanged. Browsers lacking Web Speech can open the voice screen and explicitly select configured NIM if media capture is supported. This is not true streaming ASR or guaranteed uninterrupted capture under OS policies; device and actual configured NIM service tests remain necessary. PWA cache v193.

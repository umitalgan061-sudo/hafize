# Hata Mesajları

Hata metinleri başarısız eylemi tarif eder ancak storage içeriğini açıklamaz.

Örnekler:
- Yerel veri özeti yenilenemedi.
- Bazı yerel alanlar temizlenemedi.
- Gizlilik raporu oluşturulamadı.
- Rapor panoya kopyalanamadı.
- Toplu temizleme iptal edildi.

Hatalar sessizce başarılı gibi gösterilmez.

Clipboard veya estimate yokluğu product failure olarak kabul edilmez; temel inventory yine kullanılabilir.

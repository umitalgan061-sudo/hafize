# Yüzey Özeti Kopyalama

Her dolu yüzey satırı kendi içeriksiz özetini panoya aktarabilir.

Özet yalnız label, key sayısı ve byte büyüklüğünü içerir.

Raw storage value hiçbir yüzey copy akışına girmez.

Copy eylemi yalnız kullanıcı tıklamasıyla başlar.

Clipboard API başarısızsa kullanıcıya hata durumu gösterilir.

Bu işlem storage verisini değiştirmez.

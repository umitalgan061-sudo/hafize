# Koleksiyon Yerelleştirme

Mevcut UI Türkçedir.

Collection labels:
- Koleksiyonlar
- Tüm koleksiyonlar
- Koleksiyonsuz
- Seçilenleri ata
- Otomatik atama kapalı
- Koleksiyon oluştur
- Adını değiştir
- Sil

Status messages kısa ve bounded tutulur.

Collection name kullanıcı tarafından Türkçe karakterlerle yazılabilir.

Duplicate name karşılaştırması tr-TR locale lower-case kullanır.

ID'ler locale dönüşümünden etkilenmez.

Keyboard shortcut label kullanıcıya Meta/Ctrl eşdeğerini belirtir.

Import payload source string sabit İngilizce teknik tanımdır; kullanıcı UI'sı değildir.

Future localization için label map tek modülde toplanabilir.

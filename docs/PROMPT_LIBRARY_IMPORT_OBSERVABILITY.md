# Import observability

Import remote telemetry üretmez.

Yerel kullanıcı geri bildirimi status alanından verilir:

- dosya geçersiz
- kapasite aşıldı
- preview hazır
- import tamamlandı
- storage hatası

Teknik teşhis gerekiyorsa diagnostics report kopyalanabilir; rapor prompt body içeriğini içermez.

Bu yaklaşım hem gizliliği hem deterministik davranışı korur.

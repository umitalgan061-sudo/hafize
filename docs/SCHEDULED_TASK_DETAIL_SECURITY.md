# Görev Ayrıntıları Güvenlik

Ayrıntı modalı salt-okunurdur. Task row'daki görünür metadata dışında veri çekmez.

Yeni fetch, XMLHttpRequest veya storage yazımı yapılmaz. Dinamik görev metni textContent ile gösterilir.

Ayrıntı görüntülemek schedule status, ownership veya authentication kararlarını değiştirmez.

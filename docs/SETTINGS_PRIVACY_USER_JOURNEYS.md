# Kullanıcı Yolculukları

## İnceleme
Kullanıcı Ayarlar'a girer, yerel veri özetiyle hangi yüzeylerin dolu olduğunu görür. Arama alanı uzun yüzey listesinde hızlı gezinmeyi sağlar.

## Tek yüzey temizleme
Kullanıcı tek bir yüzey seçer. Confirm sonrası yalnız o yüzeyin exact/prefix key'leri kaldırılır.

## Veri temizleme
Kullanıcı tercihleri koruyarak kullanıcı verilerini topluca temizleyebilir. Bu işlem tekrar onay ister.

## Tam reset
Kullanıcı tüm bilinen alanları temizlemek için iki aşamalı onay kullanır. Bilinmeyen key'ler korunur.

## Rapor
Kullanıcı JSON raporu indirebilir veya kısa, içeriksiz özeti panoya kopyalayabilir.

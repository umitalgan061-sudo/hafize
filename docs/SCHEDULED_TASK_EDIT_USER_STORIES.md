# Schedule Edit User Stories

### Yeniden zamanlama
Kullanıcı bir planlanmış görevin zamanını değiştirmek ister ve mevcut görevin kimliği korunur.

### İçerik düzeltme
Kullanıcı task metnindeki bir hatayı düzeltir; execution başlamadıysa aynı schedule devam eder.

### Ajan değiştirme
Kullanıcı uygun registry ajanını seçerek planlanmış işin yürütücüsünü değiştirir.

### Hızlı erteleme
Kullanıcı paneli açmadan karmaşık form kullanmadan görevi 15 dakika veya 1 saat ileri alabilir.

### Toplu bakım
Kullanıcı birden fazla planlanmış görevi seçerek aynı erteleme veya iptal işlemini uygulayabilir.

### Kopyalama
Kullanıcı mevcut planı yeni bir schedule olarak tekrar oluşturabilir; geçmiş kayıt değişmez.

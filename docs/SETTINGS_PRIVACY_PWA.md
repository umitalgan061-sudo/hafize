# PWA Entegrasyonu

Privacy Center CSS ve JS dosyaları index.html tarafından yüklenir.

Service Worker shell listesi iki asset'i cache'e alır.

Cache version bump eski shell cache'lerinin temizlenmesini sağlar.

Privacy data localStorage'da kalır; service worker storage içine kullanıcı verisi yazılmaz.

API routes network-only olmaya devam eder.

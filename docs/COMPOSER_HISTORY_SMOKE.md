# Composer History — Smoke Akışı

1. Uygulamayı aç.
2. Composer içine `smoke-one` yaz.
3. Mesajı gönder.
4. Composer temizlendiğinde `↑` bas.
5. `smoke-one` geri gelmeli.
6. `↓` bas ve mevcut draft akışını kontrol et.
7. `Geçmiş` panelini aç.
8. Kaydı gör.
9. Aramaya `smoke` yaz.
10. Kayıdı `Kullan` ile composer'a aktar.
11. Gönderme gerçekleşmemeli.
12. `Sil` ile kaydı kaldır.
13. History panelinin boş state'ini gör.
14. Yeni mesaj gönder.
15. `Geçmiş gizlilik ayarları` bölümünü aç.
16. Saklama limitini 10 yap.
17. Yeni birkaç mesaj gönder.
18. On birden fazla kayıt oluşmadığını kontrol et.
19. History'yi kapat.
20. History key'inin bulunmadığını kontrol et.
21. History'yi tekrar aç.
22. Yeni mesaj gönder.
23. Tek yeni kayıt oluştuğunu kontrol et.
24. Backup export çalıştır.
25. JSON dosyasını kontrol et.
26. Backup import çalıştır.
27. Duplicate kaydın oluşmadığını kontrol et.
28. `Ctrl/⌘ + Shift + H` ile paneli aç/kapat.
29. Escape ile paneli kapat.
30. Sayfayı yenile.
31. Composer'ın çalıştığını kontrol et.
32. History'nin retention ayarına uygun kaldığını doğrula.
33. Console'da history kaynaklı exception olmadığını doğrula.
34. Network tabında history modülünden çağrı olmadığını doğrula.
35. Offline PWA açılışında history assetlerinin yüklendiğini kontrol et.
36. Test sonucunu release kaydına yaz.

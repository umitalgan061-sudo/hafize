# Operating Model

Feature yalnız browser-side local data yönetimi sağlar.

Backend değişikliği yoktur.

Persistent storage için explicit allowlist kullanılır.

Unknown storage area discovery sonucu silinmez.

Kullanıcı verisi ile preference alanları ayrı temizleme komutlarına sahiptir.

Raporlama content-free'dur.

Workspace Backup gerçek recovery için ayrı yüzeydir.

PWA yalnız feature asset'lerini shell cache'e alır.

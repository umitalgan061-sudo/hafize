# Model ve Ajan Tercihleri Örnekleri

## Yazı profili

Model: seçilen genel model.
Ajan: yazı uzmanı.
Araçlar: kapalı.
Profil adı: Yazı düzenleme.

## Kod profili

Model: seçilen kod modeli.
Ajan: kod uzmanı.
Araçlar: açık veya kapalı.
Profil adı: Kod inceleme.

## Araştırma profili

Model: seçilen genel model.
Ajan: araştırma uzmanı.
Araçlar: backend policy izin veriyorsa açık.
Profil adı: Araştırma.

## Günlük kullanım

1. Composer'dan model seçilir.
2. Ajan seçilir.
3. Araç modu gerektiğinde açılır.
4. Tercihler paneli açılır.
5. Mevcut seçim profil olarak kaydedilir.
6. Sonraki sohbette profil uygulanır.

## Import örneği

Export dosyası başka bir cihazdan alınır.
İçe aktar seçilir.
Geçerli ve reddedilen kayıt sayısı gösterilir.
Kullanıcı onay verirse yeni profiller eklenir.
Mevcut ID'ler overwrite edilmez.

## Sıfırlama örneği

Kullanıcı Tercihleri sıfırla seçer.
Açık onay verir.
Son model, son ajan ve profiller temizlenir.
Conversation history korunur.

## Güvenli kullanım örneği

Profil adına erişim tokenı yazmak yerine açıklayıcı genel bir ad kullanılır.
Secret bilgileri export dosyasına eklenmez.
Dosya yalnız güvendiğin ortamda saklanır.

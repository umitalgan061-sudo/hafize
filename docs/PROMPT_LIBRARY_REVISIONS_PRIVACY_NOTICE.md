# Revision History Privacy Notice

Revision history, Prompt Library içindeki metinlerin önceki durumlarını cihaz üzerinde tutar.

Bu kayıtlar istem başlığı, gövdesi ve etiketlerini içerebilir.

Revision storage server-side değildir.

Uygulama revision içeriğini analytics, telemetry veya connector servisine göndermez.

History yalnız mevcut browser profilinde kullanılabilir.

Tarayıcı site verileri temizlenirse history kaybolabilir.

Kullanıcı cihazı değiştirdiğinde history otomatik taşınmaz.

Export seçeneği history'yi kullanıcı tarafından seçilen download konumuna çıkarır.

Export dosyası paylaşılmadan önce hassas bilgiler kontrol edilmelidir.

Restore işlemi kullanıcı onayı gerektirir.

Restore öncesi mevcut prompt manual snapshot olarak korunur.

Favorite ve useCount restore ile geriye dönmez.

History clear ana prompt'u silmez.

Revision retention prompt başına 10 kayıt ile sınırlıdır.

Revision map en fazla 120 prompt işler.

Uzun içerikler bounded olarak normalize edilir.

HTML ve script payload'ları HTML olarak yürütülmez.

Storage parse hataları kontrollü biçimde ele alınır.

Private browsing ortamlarında storage hatası oluşabilir.

Support taleplerinde raw revision body paylaşmak yerine redacted örnekler önerilir.

Bu notice özelliğin local-only tasarım sınırlarını açıklamak içindir.

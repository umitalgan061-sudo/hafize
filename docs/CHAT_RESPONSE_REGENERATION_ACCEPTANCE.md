# Kabul Kriterleri

## A1
Son assistant mesajı için Yeniden üret düğmesi görünür ve aktif olur.

## A2
Eski assistant mesajları için Yeniden üret pasif olur.

## A3
Regeneration aynı conversation'ın önceki message turn'lerini kullanır.

## A4
Başarılı response eski content'i alternate history içine alır.

## A5
Başarısız response eski content'i kayıpsız geri koyar.

## A6
Restore latest alternate current response ile güvenli şekilde yer değiştirir.

## A7
Alternatif history üç kayıt ile sınırlıdır.

## A8
Feedback state positive, negative veya absent olabilir.

## A9
Copy yalnız mevcut assistant content'ini panoya verir.

## A10
Hiçbir response action composer submit tetiklemez.

## A11
Tool mode açıkken agent endpoint kullanılır.

## A12
Offline durumda request başlamaz.

## A13
Secret veya OAuth token browser state'e yazılmaz.

## A14
Yeni backend route gerekmez.

## A15
Typed build kaynakları Vite pipeline ile derlenebilir olmalıdır.

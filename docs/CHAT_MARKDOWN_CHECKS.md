# Chat Markdown Checks

Bu turda merge öncesi kontrol sırası: parser, security, rendering, streaming, PWA, accessibility ve ownership. Full repository check çalıştırılamazsa bunun nedeni PR açıklamasında açıkça yazılır.

Minimum DoD: asistan yanıtı Markdown olarak okunur, raw HTML çalışmaz, güvenli olmayan URL tıklanamaz, code copy yalnız kullanıcı etkileşimiyle yapılır, uzun içerik bounded kalır, mobile overflow kontrol edilir ve mevcut conversation/message storage sahipliği değişmez.

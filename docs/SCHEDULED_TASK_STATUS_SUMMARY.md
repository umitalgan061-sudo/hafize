# Görev Durum Özeti

Görevler panelinin durum özeti beş sayaç gösterir. Her sayaç bir durum filtresine düğme olarak bağlanır.

Planlandı, Çalışıyor, Tamamlandı, Başarısız veya İptal edildi sayacına basmak mevcut liste filtresini değiştirir. Yeni HTTP isteği oluşturulmaz.

Sayaçlar liste DOM'undan hesaplandığı için schedule backend state'i değiştirilmez.

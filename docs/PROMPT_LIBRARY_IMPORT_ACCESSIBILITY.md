# Import preview erişilebilirlik sözleşmesi

## Dialog
İçe aktarma önizlemesi role=dialog ve aria-modal=true ile işaretlenir.

## Başlık
aria-labelledby dialog başlığına bağlanır.

## Odak
Panel açılırken açıcı element hatırlanır. Kapanınca odak geri verilir.

## Klavye
Escape kapanır. Tab ve Shift+Tab son/ilk odaklanabilir elementler arasında döner.

## Uyarılar
Geçersiz dosya, kapasite aşımı ve storage hataları textContent ile görünür.

## Mobil
Panel alt hizalı ve ekranın büyük bölümünü kullanabilir.

# Backup Sınırı

Privacy report bir recovery backup değildir.

Report restore edilemez; yalnız inventory bilgisidir.

Workspace Backup ise gerçek local data restore mekanizmasıdır.

Bu iki formatı aynı schema altında birleştirmek risklidir.

Privacy Center code rollback'i data restore işlemi başlatmaz.

Kullanıcı silme öncesinde ayrı backup flow kullanmalıdır.

# Görev Satırı Hızlı Eylemleri

Görev satırlarında görev metnini ve Trace ID'yi panoya kopyalayan iki yardımcı eylem bulunur.

Kopyalama yalnız açık kullanıcı tıklaması ile çalışır. Eylemler schedule API'ye istek göndermez ve görev durumunu değiştirmez.

Panoya kopyalama başarısızsa workspace durum metninde uyarı gösterilir. Dinamik metin HTML olarak işlenmez.

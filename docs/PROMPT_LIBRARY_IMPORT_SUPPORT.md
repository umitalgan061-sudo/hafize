# Import destek notları

## “Dosya geçersiz”
JSON parse edilememiştir. Aynı dosyayı yeniden kaydetmek veya başka bir editorle doğrulamak gerekir.

## “Kapasite dışında”
Kütüphanede 120 kayıt sınırına ulaşılmıştır.

## “Storage kaydedilemedi”
Tarayıcı storage erişimi başarısız olabilir; mevcut kayıtlar korunur.

## “İçe aktarma butonu pasif”
Plan içinde kabul edilebilir kayıt yoktur.

## Recovery
Recovery JSON yalnızca kullanıcı cihazında oluşur.

# Dolu Yüzey Filtresi

"Yalnız dolu yüzeyler" seçildiğinde present true olmayan satırlar gizlenir.

Bu filtre storage'daki hiçbir değeri değiştirmez.

Search aktifken iki filtre birlikte çalışır.

Filtre açıldığında grup başlıkları korunur.

Hiç sonuç yoksa mevcut boş liste davranışı korunur.

Checkbox erişilebilir bir label ile eşleştirilir.

# Kapasite Yönetimi

Inventory key/value byte toplamını yaklaşık kapasite göstergesi olarak kullanır.

navigator.storage.estimate desteklenirse browser usage ve quota ayrıca gösterilir.

%80 ve %90 eşikleri kullanıcıyı bilgilendirir.

Uygulama bu eşiklerde otomatik temizlik yapmaz.

Kullanıcı hangi yüzeyi temizleyeceğine kendisi karar verir.

Workspace Backup kapasite temizliği değil recovery mekanizmasıdır.

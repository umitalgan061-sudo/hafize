# Gelecek Genişletmeler

Olası sonraki geliştirmeler:
- yüzey bazlı retention tercihleri,
- periyodik local cleanup reminder,
- storage trendini yalnız cihazda hesaplama,
- daha ayrıntılı browser quota görselleştirmesi.

Bunların hiçbiri mevcut turda otomatik silme veya remote analytics eklememelidir.

Yeni bir feature privacy center kapsamını genişletiyorsa önce allowlist, backup ve test matrix güncellenmelidir.

Kullanıcı onayı gerektiren bir davranış silently enabled edilmemelidir.

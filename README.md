# Hafize

Hafize yapay zeka uygulaması deposu.

> Bu ilk commit yalnızca tamamen boş GitHub deposunu başlatmak ve sonraki tüm geliştirmeleri branch + Pull Request akışına geçirmek için oluşturulmuştur.

## Geliştirme

```bash
npm run check   # syntax kapısı + tüm testler (npm test ile aynı)
npm start       # yerel sunucu
```

Kontrol kapısı hedeflerini dosya sisteminden keşfeder; ayrıntı için
[`docs/CHECK_GATE.md`](docs/CHECK_GATE.md). Geliştirme kuralları
[`HAFIZE_RULES.md`](HAFIZE_RULES.md) dosyasındadır.
